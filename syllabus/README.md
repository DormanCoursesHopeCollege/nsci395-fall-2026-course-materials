## Why there is no copy here

A second copy of the syllabus or the schedule in this repository would drift
from the real one, and you would have no way to tell which was current. So this
folder holds a link instead of a duplicate.

The schedule is tentative by design. When it changes, the Google Doc is updated
and the change is announced in class and in Moodle.
